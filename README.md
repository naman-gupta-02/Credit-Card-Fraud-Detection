# Credit-Card-Fraud-Detection
"Credit Card Fraud Detection using SVC" Git repository – your gateway to a cutting-edge machine learning project that harnesses Support Vector Classification (SVC) to identify and combat credit card fraud. This project showcases the power of machine learning in safeguarding financial transactions and ensuring the security of credit card holders.


## Datasets
- `detection.py` uses `creditcard.csv` (included as `creditcard.csv.zip`; unzip it first).
- `detection2.py` uses `fraudTrain.csv` and `fraudTest.csv` from the [Credit Card Transactions Fraud Detection Dataset](https://www.kaggle.com/datasets/kartik2112/fraud-detection) on Kaggle. They are too large for GitHub, so download them and place them next to the script.
